# 自由 · 股息收入追踪

一个**单文件网页应用**：记录持仓与分红、自动同步分红方案、预测年度分红、看股息覆盖生活的进度与账户的深度分析。它是微信小程序「息记」（原名「收息佬」）的精简复刻版。

双击 `dist/自由.html` 即可在 **Windows / macOS 电脑、安卓手机、iPhone、iPad** 上使用，无需安装、无需注册、无需服务器。数据全部保存在你自己的浏览器里。

> **只做记录。** 本应用不提供股票买卖、不推荐标的、不提供任何投资建议或收益承诺。

---

## 快速开始

1. 双击打开 **`dist/自由.html`**（或在手机上访问部署好的网址）
2. 点右下角悬浮 **＋** → 「✏️ 手动添加」
3. 三步填完：**选股**（按名称/代码搜索）→ **持仓信息**（数量、成本、成本口径）→ **分红预测口径**
4. 首页即刻显示：预测年度分红、成本息率、市值息率、月均预测分红、分红覆盖进度

### 当 PWA 用（推荐）

```bash
node build.mjs     # 生成 dist/自由.html 与 dist/pwa/
```

把 `dist/pwa/` 部署到任意静态托管（本仓库走 GitHub Pages）。手机浏览器打开网址后：iOS Safari「分享 → 添加到主屏幕」、安卓 Chrome「安装应用」。装好后是全屏 App：图标是玻璃水滴，首次在线打开后断网也能进入（Service Worker 缓存应用外壳），行情与分红仍会联网实时获取。

## 功能一览

### 持仓（首页）
- **年度分红卡**（深色）：收息第 N 天 · 预测年度分红 · N 年可达 X 倍
- **6 个可自定义指标**：今年已收 / 总成本 / 总市值 / 成本息率 / 市值息率 / 月均预测分红（配 `?` 白话解释）
- **测算带**：年投 × 息率 → N 年后月均，5 个数字可点改、可反解年数/年投
- **资产走势**：持仓市值 / 净资产 / 收益率（TWR），7 档区间、指数对比、当日分时
- **持仓卡片**：官方图标 / 红涨绿跌徽章 / 技术信号标记 / 分时 sparkline / 四列数据
- **排序 6 档** 与 **市场筛选**；悬浮双入口：✏️ 手动添加 · 📷 截图识别

### 分红日历 / 计划 / 分红汇总
- 待除权提示（除权日已定 + 除权日待定两类）、月历三色点（登记/除权/派息）、年度总览 12 月柱状
- 计划页：分红覆盖（支出项逐个点亮）、里程碑、下一目标反推、展望未来
- 分红汇总：五个时间档位、已到账与预计严格分列、趣味换算、按标的展开

### 个股详情
预测年分红（口径可切）· **股息率十年曲线**（除权散点 + 两口径均线 + 余额宝基准 + brush 缩放）· 双息率（股价息率 + 成本息率）· 持仓明细 · 交易明细 · 回本进度 · 分红档案 · 分红记录

### 截图识别（OCR）
选券商持仓截图（支持多张）→ 智谱 GLM-4V 识别 → 逐行核对修正 → 批量导入。首次使用有隐私确认；部署版的 Key 已置空，需到「我的 · 截图识别设置」填一次（[免费申请](https://open.bigmodel.cn)）。

### 我的
账户管理 · 交易流水 · 数据管理（JSON 导出/导入 · 交易流水 CSV · 分红台账 CSV · 跨设备搬运 · 清空）· 设置

**跨设备搬运**：把核心数据编码成一段 `XJ1…` 文本或链接（gzip 压缩，不含 OCR Key），用微信/QQ 发到另一台设备，粘贴或打开即导入，可选**合并（自动去重）**或**覆盖**；不经过任何服务器。

**从息记迁移**：在旧版「息记」里「导出全部数据（JSON）」，再到「自由 · 导入数据（JSON）」导入即可（数据结构同源，完全兼容）。

## UI 与深色模式

界面为 **iOS Liquid Glass 风格**：全量玻璃质感卡片、高光描边、环境光斑背景；支持**浅色 / 深色双模式**（跟随系统）。语义色不随主题变化：涨红 `#E0312F`、跌绿 `#12A150`、分红橙红 `#E8461F`。

## 数据来源与口径

| 数据 | 来源 |
|---|---|
| A股 / 港股 / 美股 / ETF 行情 | 腾讯财经 `qt.gtimg.cn`（GBK，`<script charset>` 注入） |
| 汇率（HKD/CNY、USD/CNY） | 腾讯财经 `qt.gtimg.cn/q=whHKDCNY,whUSDCNY` |
| 当日分时 / 历史日线 | 腾讯 `web.ifzq.gtimg.cn`（不复权） |
| A股分红送配 | 东方财富 `RPT_SHAREBONUS_DET`（JSONP） |
| 港股分红（含独立派息日） | 东方财富 `RPT_HKF10_MAIN_DIVBASIC` |
| 基金 / ETF 分红与净值 | 天天基金公开接口 |
| 股票搜索 | 腾讯联想 `smartbox.gtimg.cn` |
| 官方图标 | icon.horse / api.xinac.net / 同花顺 F10（canvas 采样验真，防占位图） |
| 截图识别 | 智谱 AI `open.bigmodel.cn` · GLM-4V（直连，无后端） |

> 除 OCR 外全部通过 `<script>` 注入或 JSONP 实现，绕开跨域限制，`file://` 下可直接使用。

**核心口径**（详见源码注释与 verify.mjs 断言）：
- 预测年度分红 = 持股数 × 财年口径年均每股分红（近 N 个完整财年，含预案降级链）
- 持仓成本三口径（每只标的独立选，默认**分红摊薄**）：分红到账后成本自动下降，允许为负
- 持仓永远由 `transactions` 推导，无持仓表；改数量/改成本 = 追加交易/成本调整记录
- 金额一律折人民币（`*Cny` 成对字段）；每股数字保留原币
- 技术信号：BOLL(20,2) 下轨 + KDJ(9,3,3) J<0，文案中性（「日线下轨」/「周线下轨」），不构成投资建议
- 分红统一**税前**口径；美股无免费分红源，手工补录

## 架构预留（跨设备同步）

精简版**已移除**跨设备同步层（Gist 传输 / 口令配对 / 二维码）。但为将来接回预留了完整挂载点，接回时**零核心改动**：

1. `state.syncMeta` 空壳结构原样保留（`model.js`），`enabled` 恒为 `false`；`toExport` 只导出空壳、绝不带令牌，`fromImport` 默认丢弃、本机自加载 `keepSync` 保留——语义与同步在位时完全一致
2. `storage.setOnBeforeSave` 落盘前钩子保留（`storage.js`），同步层当年正是挂在这里「落盘前算增量」
3. `boot()` 里留有占位注释标明挂载位置（`app.js`）

verify.mjs【32】有 7 条锚断言钉住以上语义，防止预留结构在迭代中被悄悄破坏。

## 开发

```bash
node build.mjs          # 重新构建两份产物（改了 src/ 之后必须执行）
node verify.mjs         # 数值验收：独立复算 1300+ 项断言，与页面结果逐位比对
node uitest.mjs         # 多端 UI 验收：9 视口 × 全部视图 + 弹层（CDP 驱动，全程断网）
node livetest.mjs       # 真实数据链路端到端验证（行情/分红/图标/OCR）
node tools/smoke-prune.mjs   # 快速冒烟：四 Tab / 弹层 / summary 复算 / 零同步痕迹
node tools/shoot-theme.mjs   # 深浅双模式截图 + token 断言
node tools/make-icons.mjs    # 重新生成 PWA 图标（改动设计后）
```

**架构约束**：`views → store → calc / fetcher`，严格单向。`calc.js` 全部纯函数，可被 `verify.mjs` 在 Node 沙箱中直接加载做独立复算。页面显示的每个数字都能在 verify.mjs 找到对应断言。

```
src/
├── util.js        日期 / 数值 / 格式化 / 下载
├── market.js      市场抽象：代码规范化 · 币种 · 行情字段 · 图标候选链
├── model.js       数据模型 v5 · 校验 · 导入导出 · CSV · 迁移 · syncMeta 空壳
├── storage.js     IndexedDB → localStorage 降级 + 落盘前钩子槽
├── transfer.js    跨设备搬运（gzip + base64url · 合并去重，纯函数）
├── fetcher.js     取数层（行情/汇率/搜索/分红/分时/历史/图标，script 注入）
├── ocr.js         截图识别（智谱 GLM-4V，含提示词与输出解析）
├── chart.js       图表（对比曲线 · 分时 sparkline · 散点 · brush，零依赖内联 SVG）
├── calc.js        计算引擎（全部纯函数：三口径/TWR/股息率曲线/信号/预测…）
├── store.js       单一状态源 + 订阅
├── ui.js          图标 / 弹层 / Toast / 事件委托
├── views/         overview · calendar · plan · divsummary · analysis · networth · symbol · mine
└── app.js         启动 / 路由 / 全部交互动作
```

## 部署（GitHub Pages）

产物 `dist/pwa/` 已提交进仓库，两种方式：

1. **Actions 自动部署（推荐）**：仓库 Settings → Pages → Source 选「GitHub Actions」，之后每次 push 到 main 自动部署（workflow 见 `.github/workflows/deploy-pages.yml`）
2. **一键脚本**：`node tools/deploy-github.mjs`（Contents API，GitHub 令牌放未跟踪的 `.token` 文件，`repo` 权限）

部署后验证：网址可达、SW 注册成功（缓存名 `ziyou-<hash>`）、手机添加主屏幕（名字「自由」、水滴图标、深浅跟随系统）。
